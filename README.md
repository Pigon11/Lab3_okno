# Лабораторная работа №3 — Работа с SQL в PyQt5

## Описание программы
Программа представляет собой приложение на PyQt5 для работы с базой данных SQLite. В качестве базы данных используется файл `rpl.db` (Российская Премьер-Лига), содержащий таблицу `teams` с информацией о футбольных командах.

**Архитектура проекта:**
- `main.py` — точка входа в приложение.
- `okno.py` — интерфейс, меню, кнопки, вкладки и логика взаимодействия с БД.
- `database.py` — модуль для подключения/отключения от БД.
- `rpl.db` — файл базы данных SQLite.

**Реализованный функционал:**
1. **Меню `Database`**:
   - `Set connection` — открывает QFileDialog для выбора файла `.db` и подключается к нему.
   - `Close connection` — очищает все вкладки и закрывает соединение.
   - `Custom Query (Bonus)` — открывает модальное окно для ручного ввода SQL-запроса и вывода результата.
2. **Вкладки**:
   - **Tab1**: автоматически выполняет `SELECT * FROM sqlite_master` при подключении.
   - **Tab2**: кнопка `bt1` выполняет `SELECT name FROM sqlite_master`.
   - **Tab3**: QComboBox позволяет выбрать колонку (`type`, `name`, `tbl_name` и т.д.) и выполнить `SELECT <колонка> FROM sqlite_master`.
   - **Tab4**: кнопка `bt2` выполняет запрос к таблице `teams` (команды и очки).
   - **Tab5**: кнопка `bt3` выполняет запрос к таблице `teams` (команды и забитые голы, сортировка).
## Ход выполнения работы

1. **Подготовка базы данных.** 
   С помощью программы DB Browser for SQLite я создал файл базы данных `rpl.db`. В нём была создана таблица `teams` (команды, город, очки, забитые голы) и заполнена данными Российской Премьер-Лиги.

2. **Создание структуры проекта.**
   Проект разделён на три файла:
   - `database.py` — класс для подключения к базе данных через `QSqlDatabase`.
   - `okno.py` — главное окно с меню, кнопками, QComboBox и пятью вкладками.
   - `main.py` — точка входа для запуска приложения.

3. **Реализация подключения.**
   При выборе пункта меню `Set connection` открывается `QFileDialog`, где я выбираю файл `rpl.db`. После выбора программа подключается к базе и выводит сообщение об успехе. Сразу после этого в Tab1 автоматически выполняется запрос `SELECT * FROM sqlite_master`.

4. **Настройка интерфейса.**
   Созданы три кнопки (`bt1`, `bt2`, `bt3`) и выпадающий список `QComboBox`. При подключении список заполняется системными колонками (`type`, `name`, `tbl_name`, `rootpage`, `sql`).

5. **Реализация запросов.**
   - Кнопка `bt1` выводит в Tab2 имена объектов из `sqlite_master`.
   - Выбор колонки в `QComboBox` выводит её содержимое в Tab3.
   - Кнопка `bt2` выводит в Tab4 таблицу команд с очками.
   - Кнопка `bt3` выводит в Tab5 таблицу команд с забитыми голами (сортировка по убыванию).

6. **Бонусное задание.**
   Добавлен пункт меню `Custom Query`, который открывает модальное окно (`QDialog`) для ручного ввода SQL-запроса и отображения результата в таблице.

## Технологии
- Python 3.8+
- PyQt5
- SQLite 3

## Запуск
1. Установите зависимости:
```bash
pip install PyQt5
```
2. Запустите программу:
```bash
python main.py
```
3. В меню выберите `Database -> Set connection` и укажите файл `rpl.db`.
